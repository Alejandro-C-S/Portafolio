# Portfolio — Alejandro

Portafolio web personal desarrollado para presentar mis proyectos, experiencia académica y habilidades como desarrollador de software.

El proyecto está pensado como una aplicación web moderna, sencilla de navegar y enfocada en mostrar tanto el resultado visual de mis proyectos como las tecnologías utilizadas en su desarrollo.

## Instalación

Clona el repositorio:

```bash
git clone https://github.com/Alejandro-C-S/Portafolio.git
```

Entra al proyecto:

```bash
cd TU-REPOSITORIO
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

Después abre la dirección indicada por Vite en tu navegador.

## Build para producción

Para generar una versión optimizada para producción:

```bash
npm run build
```

Los archivos generados estarán disponibles en:

```text
dist/
```
